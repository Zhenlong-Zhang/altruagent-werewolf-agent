# Phase C implementation contract: contextual PPO

Planner implementation proposal, 2026-11-20; requires parent/Reviewer acceptance before source changes. Parent owns `contextual_selector.py`, rollout adapter and PPO trainer. Worker owns the accepted Phase B packet/controller. Do not modify frozen Phase A source/job, D7 or R03 artifacts. Live game counts, population weights and compute caps remain blank until operation-only throughput is measured.

## A. Frozen inputs and selector API

Input is one immutable `strategy-observation-v2` packet and its complete validated candidate list, with packet hash and `(session_hash, acting_seat)` ownership verified recursively. A lineage pins rules/packet/controller/realizer/generator/model/encoder/serializer versions. The acting seat's own parsed role is allowed; evaluation-only role lists, terminal returns and other-seat private information are forbidden. No model-written inference becomes a verified fact. All candidate source references must resolve in this packet/its protected projection.

Public interface:

`ContextualSelector.choose(packet, candidates, deadline=..., decision_id=None) -> Choice`

Parent/Reviewer source-architecture acceptance: constructor owns immutable deployment mode and owner-local RNG. Preserve the Phase B09 required return keys `index`, `probabilities`, `log_probability`, `value`, `checkpoint_id`, `metadata`. Additional replay fields below are aliases/metadata, not incompatible replacement keys. An optional caller decision_id binds the controller record; otherwise the selector supplies a unique draw/decision reference, returned to the caller. Explicit protected-ledger/ballot/pending mapping must be agreed before collector integration. Source primitive implementations may proceed independently of that adapter binding. Live collection still requires actual throughput and finite budgets below.

`Choice = {index, candidate_id, probabilities, log_probabilities, selected_logp, value, checkpoint_id, serializer_id, encoder_id, packet_hash, candidates_hash, mode, selection_kind, draw_id, elapsed, error}`.

`mode` is `sample` or `greedy`; `selection_kind` is `sampled`, `forced_singleton`, `greedy` or `fallback`; `draw_id` is unique only for actual categorical draws. RNG seed/state belongs to this owner, never a shared mutable cross-seat stream. `value` is a scalar behavior prediction from the frozen critic **before the request**. Return full logits/log-probabilities for every offered candidate. Deadline/error fallback returns an explicitly marked deterministic choice, never a fake sampled distribution. A timed-out model result is not delivered later. Selector contains no transport or terminal-result access and cannot update parameters during games. Separate `serialize(packet,candidates)` and `evaluate(serialized)` paths support exact replay.

## B. Deterministic slot serializer `contextual-slots-v1`

Day/age use `min(max(value,0),16)/16`; counts use declared cap-normalization. Unknown timing has value0 plus a knownness bit. Exact raw source/ID mapping remains in replay metadata. Text slots use the pinned frozen MiniLM384 masked-mean/L2 pooling, eval mode and256-wordpiece maximum **per slot**. Candidate/source excerpts are bounded upstream; protected typed assertions never depend on token truncation.

## C. Actor, critic and licensed reuse

Frozen MiniLM384 encoder; per-type numeric-plus-text projection to128, learned slot-type embedding, two width128/four-head attention blocks, dropout0, no absolute slot-position embeddings. Candidate scalar head scores each candidate against its contextual representation. Actor sees state, protected self commitments and candidates jointly. Separate critic has independently parameterized projections/blocks and a pooled global scalar value head; it sees only the same acting-seat packet and observed candidate set. Share frozen text embeddings only. Critic-only training must leave actor logits byte-identical on the same serialized fixture.

Adapt SLA `onpolicy/algorithms/mat/algorithm/ma_transformer.py` `SelfAttention`/`EncodeBlock` at `c81f4500b0be74e4a270370ba35bb94caceb915b` to one seat's slots, adding padding/relation masks. Do not import the full MAT joint-agent/action decoder. Reuse MAPPO `onpolicy/algorithms/r_mappo/r_mappo.py` clipped policy/value-loss primitives, `onpolicy/utils/shared_buffer.py` return recurrence and `onpolicy/algorithms/utils/distributions.py` masked categorical semantics at `de66d7a4b23fac2513f56f96f73b3f5cb96695ac`. Parent's isolated adaptations live in `werewolf_agent/vendor/slot_attention.py` and `event_ppo.py`; bind their reviewed source hashes before collector deployment. New event storage/scorer are explicitly adaptations. Keep MIT notices in vendored/adapted headers and license manifest with source hashes/change notes. No claim of exact SLA or centralized MAPPO reproduction.

## D. Collector, request MDP and return masks

Initially exactly **one learning focal seat per game**; other seats use frozen population members. Only this seat's sampled requests train PPO. Other-seat legal logs can supply separately tagged BC examples only under their own visible packets; no joint-private actor input. A policy timestep is an actual request choice, not a poll, ACK callback or generated token. Each row stores immutable packet/slate+hashes, behavior values/full log-probabilities, chosen request, unique decision/delivery IDs and executor outcome, next decision link, terminal result and masks. Generator/controller/realizer/executor remain frozen within a batch. Actual selection/mode must match the logged distribution.

PPO action is the sampled **request through the fixed executor**. Retain rejected and unknown requests, with exact requested action/logp and observed delivery condition; deterministic executor fallback is a separate effect, not a replacement sample. Unknown ACK does not itself invalidate a game if before-states, request propensities, subsequent authorized observations and terminal outcome are replayable. Do not condition actor inclusion on successful ACK. Missing input/propensity, wrong owner/source or unresolved terminal provenance is a separate predeclared eligibility failure, archived and reported. Ambiguous delivery may remain an observed state until reconciliation. Unknown pending state prevents further controller chat as defined in B, but does not erase the original sampled draw.

Use separate `bootstrap_b`, `trace_c`, `actor_active`, `value_active`, `reset`, `truncated` fields. Proposed gamma1/lambda0.95:

`delta_t = reward_t + bootstrap_b_t * V_old(next) - V_old(t)`

`advantage_t = delta_t + 0.95 * trace_c_t * advantage_next`

`value_target_t = advantage_t + V_old(t)`.

Within an intact episode, `b=c=1`. At known faction terminal, `b=c=0`, terminal reward is-1/+1 and next value0. Intermediate reward0. At a clean fragment boundary with an authorized next observation and frozen old value, `b=1,c=0`; it is not a loss. A network error without replayable next state is not such a boundary. Never use scheduler expiry as terminal reward. Lambda introduces event-count bias: extra speech choices change credit propagation even with gamma1. Record this estimator choice; no claim of undiscounted-unbiased GAE.

**Death is not faction terminal.** Store no fabricated decisions after death, but retain the last alive decision linked to the eventual faction terminal reward, with `b=c=0` on that final delayed transition. Do not apply a dead-seat mask that deletes this return. Actor/value eligibility belongs to the state where a decision was actually made. Forced one-candidate requests may enter value/return records, with zero actor categorical gradient. Polls/deterministic controller/executor actions have no actor term. A game with no focal action remains outcome/exposure evidence, not a fake PPO decision. Reset state by owner/session boundary; this initial contract uses feedforward persistent slots, not trainable recurrent hidden state.

Compute old values, GAE targets and advantages once before an update, then freeze through all epochs. Later rollout batches must use the previous trained critic. No same-batch critic refit followed by retroactive replacement of old values/advantages. Do not substitute a newly generated next slate for the exact stored next-decision state.

## E. Warm start, objective and rollback

If parent chooses BC, use Phase B's explicit teacher-preferred index/actual controller request, not first-candidate ordering. Game-disjoint demonstration train/development splits precede BC. Critic warm start may fit prior completed demonstration outcomes; archive its approximation and do not postfit fresh PPO outcomes before computing their old values. Freeze BC artifact `C0` as a no-PPO control. Fresh rollout/update batches produce `C1..Ck`; compare `C0` and selected `Ck` with the same generator/controller and deployment mode to identify adaptation. No old R03 coarse log is eligible. BC is learning and must not be called an untrained model.

Proposed optimizer settings to freeze on acceptance: Adam actor/critic learning rate3e-4 separately; clip ratio0.2; value clip0.2 relative to old value; value-loss coefficient1; entropy coefficient0.01; gradient norm0.5; at most10 epochs per fresh batch. No advantage normalization in this initial contract. Minibatch packing and full batch/game quantities are fixed after throughput measurements, before outcome inspection. Include the entire batch each epoch; never select high-return games.

For each focal game, **sum eligible decision actor surrogate and entropy terms**, then mean over games with at least one eligible request; games with zero requests contribute to exposure/outcome reports only. Do not change the denominator as a function of wins or number of accepted ACKs. Value loss is mean over value-eligible decisions within a game, then mean over eligible games. Natural platform role frequencies receive equal per-game training weight; do not equal-weight roles or inverse-frequency upweight a rare seer without a new declared objective. Report all counts by role; role-standardized evaluation at the fixed4/7 villager,1/7 seer,2/7 wolf mixture is a separate diagnostic. If later collecting more than one learner seat/game, revise the contract before collection to normalize seat/game weights and retain game-level dependence.

Before every optimizer step snapshot **both networks, both optimizer states and any learned normalization state**. Compute exact full categorical `KL(old||new)` on all actor-eligible collected slates after the step; mean threshold0.02 and maximum-per-slate0.1. Also check all parameters/losses/gradients finite. Violation restores the whole snapshot and halts remaining optimization; report rejected and accepted steps without retaining a violating critic update. Last accepted checkpoint is the batch output; no final-cohort choice of epochs. Check full probabilities/logps/values reproduce collector artifacts before any update (float32 tolerance fixed in tests, proposed `rtol1e-5,atol1e-6`); candidate/encoder/source mismatches reject the batch. Greedy logs/BC labels cannot masquerade as sampled PPO propensities.
